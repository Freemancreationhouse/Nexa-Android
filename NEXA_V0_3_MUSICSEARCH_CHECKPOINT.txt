NEXA V0.3 MUSIC SEARCH CHECKPOINT
Brand: NEXA — Music Beyond Borders

Scope locked:
- Search-first music discovery, not radio-only.
- Query by song, artist, album, movie/soundtrack, language and free-form text.
- YouTube official Data API search + official embedded player for mainstream catalog.
- Audius direct native audio where available.
- Radio Browser live stations retained.
- No listener login and no paid subscription.
- YouTube audio extraction/background playback is explicitly not implemented.
- High-contrast song/artist titles retained across the UI.

Build baseline:
- compileSdk 36 / targetSdk 36
- AGP 9.4.0 / Gradle 9.6.0 / JDK 17 / Kotlin 2.2.10
- Compose BOM 2026.03.00 / Media3 1.9.3
- versionCode 4 / versionName 0.3.0

Required developer configuration:
- YouTube Data API v3 key may be supplied through GitHub secret NEXA_YOUTUBE_API_KEY or entered in-app under Settings.
