NEXA V0.3.1 COMPILEFIX1

Root cause fixed:
V0.3 MainActivity.kt was incomplete: 13 helper functions used by the app were referenced but not defined after the V0.3 music-search rewrite. This causes :app:compileDebugKotlin to fail.

Restored/implemented:
- SectionTitle
- StatCard
- EmptyState
- LoadingBlock
- ErrorBlock
- SourceFooter
- BottomBar
- PlayerAction
- formatTime
- saveTracks
- loadTracks
- sourceLabel
- share

V0.3 persistence is source-aware:
- RADIO and AUDIUS restore from streamUrl
- YOUTUBE restores from videoId and does not require streamUrl
- source/videoId/thumbnailUrl/durationMs persist with favorites/recent items

Build baseline intentionally preserved from the user-validated V0.2 LIVE2:
- compileSdk 36
- targetSdk 36
- AGP 9.4.0
- Kotlin Compose plugin 2.2.10
- Compose BOM 2026.03.00
- Media3 1.9.3
- Gradle 9.6.0 in GitHub Actions
- JDK 17 in GitHub Actions

A source regression preflight now runs before Gradle compilation so a truncated MainActivity/helper loss fails immediately with a precise message.
